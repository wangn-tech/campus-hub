## 2. 已确认的设计决策

1. `07-HTTP API 设计规范.md` 是新 HTTP 接口的唯一契约；`02-前端接口清单.md` 只记录旧接口，`18-前端更新.md` 只记录迁移动作。
2. 所有对外资源路径中的 `{id}` 使用 UUID 字符串，数据库内部自增 ID 不对外暴露。
3. HTTP、WebSocket 和 Kafka 的时间字段统一使用 Unix 毫秒时间戳；数据库继续使用 `DATETIME(3)`，由代码负责双向转换。
4. 分页响应统一使用 `items` 和 `pagination`，请求参数统一使用 `page`、`page_size`。
5. 邮箱验证码统一使用 `POST /api/v1/email-codes`，请求体包含 `email` 和 `scene`，不使用 GET 触发发送。
6. WebSocket 事件统一使用 `snake_case`；旧小驼峰事件名仅保留在迁移说明中。
7. WebSocket 多实例广播使用 Kafka，每个实例使用独立的 `campushub.chat-delivery.{instance_id}` 消费组；Redis 只保存连接和在线状态。
8. 报名 `expired` 是终态，超时必须释放预留名额并写入状态日志和事件。
9. 学生认证申请增加独立 `id` 和 `uuid`，`user_id` 继续唯一表示当前认证聚合，状态历史记录在事件表。
